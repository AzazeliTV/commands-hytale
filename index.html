Teleportation

/spawn
/spawn
Teleportiert dich zum Server-Spawnpunkt. Ideal, wenn du dich verlaufen hast oder schnell zurueck zum Startgebiet willst.
/home
/home [Name]
Teleportiert dich zu einem deiner gespeicherten Homepunkte. Ohne Name wirst du zum Standard-Home teleportiert.
/sethome
/sethome [Name]
Setzt einen Homepunkt an deiner aktuellen Position. Du kannst mehrere Homes mit verschiedenen Namen anlegen (Limit abhaengig vom Rang).
/homes
/homes
Zeigt eine Liste aller deiner gespeicherten Homepunkte an.
/delhome
/delhome <Name>
Loescht einen gespeicherten Homepunkt. Der Name muss exakt angegeben werden.
/tpa
/tpa <Spieler>
Sendet eine Teleport-Anfrage an einen anderen Spieler. Der Spieler muss die Anfrage akzeptieren.
/tpahere
/tpahere <Spieler>
Fordert einen anderen Spieler auf, sich zu dir zu teleportieren. Der Spieler muss die Anfrage akzeptieren.
/tpaccept
/tpaccept
Akzeptiert eine eingehende Teleport-Anfrage von einem anderen Spieler.
/tpadeny
/tpadeny
Lehnt eine eingehende Teleport-Anfrage ab.
/warp
/warp <Name>
Teleportiert dich zu einem oeffentlichen Warp-Punkt auf dem Server (z.B. Shop, Arena, Farmwelt).
/back
/back
Teleportiert dich zu deinem letzten Todespunkt zurueck. Nuetzlich, um verlorene Items einzusammeln.
/rtp
/rtp
Teleportiert dich zu einer zufaelligen Position in der Welt. Perfekt, um ein neues Gebiet zum Bauen zu finden. Reichweite abhaengig vom Rang (Default / Gold / Emerald).
/autortp
/autortp
Teleportiert dich automatisch zur maximal erlaubten Entfernung per Random Teleport.

Wirtschaft & Handel

/bal
/bal oder /money
Zeigt deinen aktuellen Kontostand an.
/pay
/pay <Spieler> <Betrag>
Ueberweise Geld an einen anderen Spieler.
/baltop
/baltop
Zeigt die Rangliste der reichsten Spieler auf dem Server an.
/shop
/shop
Oeffnet den Server-Shop als GUI-Menue. Hier kannst du Items kaufen und verkaufen.
/sell
/sell
Verkauft das Item, das du gerade in der Hand haeltst, an den Shop.
/sellall
/sellall
Verkauft alle verkaufbaren Items aus deinem Inventar auf einmal.
/ah
/ah oder /auction
Oeffnet das globale Auktionshaus. Hier koennen Spieler Items untereinander handeln und versteigern.
/ranks
/ranks oder /store
Oeffnet das Rang-Shop-Menue oder zeigt den Link zum externen Store an.

Gameplay

/kit
/kit
Oeffnet das Kits-GUI-Menue. Hier siehst du alle verfuegbaren Kits und kannst sie einloesen.
/kit claim
/kit claim <Name>
Loest ein bestimmtes Kit direkt per Befehl ein, ohne das GUI zu oeffnen. Jedes Kit hat einen Cooldown.
/job
/job
Oeffnet das Job-Auswahl-Menue. Waehle einen Beruf, um durch bestimmte Aktivitaeten extra Geld zu verdienen.
/level
/level
Oeffnet das Level- und Belohnungs-Menue. Zeigt deinen Fortschritt und verfuegbare Belohnungen an.
/pass
/pass
Oeffnet den BattlePass. Sammle EXP, um Stufen freizuschalten und Belohnungen zu erhalten.
/daily
/daily
Oeffnet das Menue fuer zeitbasierte Belohnungen (stuendlich, taeglich, woechentlich). Vergiss nicht, sie regelmaessig abzuholen!
/clear
/clear
Leert dein komplettes Inventar. Vorsicht: Alle Items gehen unwiderruflich verloren!

Kommunikation & Soziales

/msg
/msg <Spieler> <Nachricht>
Sendet eine private Nachricht an einen anderen Spieler. Alternativ: /tell
/ignore
/ignore <Spieler>
Blendet alle Nachrichten von einem bestimmten Spieler aus. Erneut eingeben, um die Sperre aufzuheben.
/msgtoggle
/msgtoggle
Schaltet den Empfang von privaten Nachrichten komplett ein oder aus.
/color
/color
Oeffnet das Menue zum Aendern deiner Nickname-Farbe (verfuegbare Farben abhaengig vom Rang).
/profile
/profile
Zeigt dein Spielerprofil mit detaillierten Statistiken in einer GUI-Uebersicht an.

Region-Schutz

/rg
/rg oder /region
Hauptbefehl fuer das Region-Schutzsystem. Verwalte geschuetzte Gebiete auf dem Server.
xqediicore.region
/pos1 & /pos2
/pos1 und /pos2
Setze den ersten und zweiten Auswahlpunkt fuer eine neue Region.
xqediicore.regionpos1 / regionpos2
/rg create
/rg create <Name>
Erstellt eine neue geschuetzte Region aus der aktuellen Auswahl.
xqediicore.regioncreate
/rg delete
/rg delete <Name>
Loescht eine geschuetzte Region dauerhaft.
xqediicore.regiondelete
/rg flag
/rg flag <Region> <Flag> <Wert>
Setzt Schutz-Flags wie PvP, Block-Break oder Interaktionen fuer eine Region.
xqediicore.regionflags
/rg list
/rg list
Zeigt eine Liste aller existierenden Regionen und deren Eigenschaften.
xqediicore.regionlist
/rg expand
/rg expand <Richtung> <Bloecke>
Erweitert die aktuelle Auswahl in eine bestimmte Richtung.
xqediicore.regionexpand
/rg redefine
/rg redefine <Name>
Aktualisiert die Grenzen einer bestehenden Region basierend auf der neuen Auswahl.
xqediicore.regionredefine
/rg tint
/rg tint <HexFarbe>
Faerbt Chunks innerhalb der Auswahl mit einer visuellen Hex-Farbe ein.
xqediicore.regiontint
/rg priority
/rg priority <Region> <Zahl>
Setzt die Prioritaet einer Region fuer Ueberlappungen.
xqediicore.regionpriority
/posclear
/posclear
Loescht die aktuellen Region-Auswahlpunkte.
xqediicore.regionposclear
